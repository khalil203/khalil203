# 🤖 K.LINKO Jarvis

Free AI voice assistant for Linko. Speaks Thai, English, French and Arabic.

**Live:** https://khalil203.github.io/khalil203/voice-call/

## Setup (free)
1. Get a free Groq key: https://console.groq.com/keys → Create API Key
2. Open the app in Chrome → ⚙️ → paste the key → 🔌 test → บันทึก (save)
3. Tap 🎙️ and talk.

## What Jarvis can do
- Fast listening (Groq Whisper) and fast answers (Groq, auto-picks the best free model)
- ⚙️ Run your Make.com automations (one line each: `name | webhook URL | description`)
- 📱 Open on the phone: call, SMS, LINE, WhatsApp, Maps, YouTube, Google, Facebook, TikTok, email
- 🧠 Memory, ✅ to-do list, ⏰ reminders (while the app is open)
- 🌤️ Weather (Open-Meteo) and 🔎 web search / news (Groq Compound)

Keys, memory and settings are stored only in your browser.
